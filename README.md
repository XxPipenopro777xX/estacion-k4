# Estación K-4 — prototipo para explorar

Mapa de una estación espacial por dentro, en primera persona, para recorrer solo o con amigos (hasta 8).

**Jugar:** https://xxpipenopro777xx.github.io/estacion-k4/

1. Escribe tu nombre.
2. Una persona aprieta **Crear partida** y comparte el código de 4 letras.
3. Los demás escriben el código y aprietan **Unirse**. Luego todos aprietan **Estoy listo**.

Controles: `WASD` moverse · ratón mirar (clic en la pantalla) · `Shift` correr · `Espacio` saltar ·
`E` abrir/cerrar puertas · `F` linterna · `Esc` soltar el ratón. Probado en Chrome.

Hecho con three.js y PeerJS (la conexión entre jugadores es directa entre los navegadores).
